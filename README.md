## 概要
「ワードバスケット」は、1台の端末をみんなで囲んで遊ぶ、順番のないしりとりカードゲームのWebアプリ版です。
場に出ているカードの文字で始まり、自分の手札の文字で終わる3文字以上の言葉を、思いついた人から先に言って手札を減らします。
インストールもログインも不要で、リンクを開いた瞬間から遊べます。

**公開URL:** [https://word-basket.giga-school.com/](https://word-basket.giga-school.com/)

詳しい操作と画面の説明は **[MANUAL.md（取扱説明書）](MANUAL.md)** にまとめています。

## できること
- **2〜6人で1台を囲んで遊べる**: 人数に応じて手札が画面の上下左右に配置され、向かいの人の手札は180度回転して表示されます。端末同士を接続する通信対戦の機能はありません。
- **制限時間を5段階から選べる**: なし（無制限）/ 10秒（激ムズ）/ 15秒 / 20秒 / 30秒。時間切れになると山札から1枚めくられてお題が自動で切り替わります。ゲーム中もボタン1つでON/OFFを切り替えられます。
- **59枚のカードと3種類の特殊カード**: ひらがな44枚に加えて、「あ行」などの行カード9枚と、「5文字」「6文字」「7文字以上」の文字数カード6枚が入っています。
- **詰まっても止まらない**: 中央の山札を押せばお題をめくり直せる「パス」、自分の場所から1枚もらえる「山札から引く」で、言葉が出てこなくてもゲームが進みます。
- **効果音つき（BGMはありません）**: カードを選ぶ・出す・引く・時間切れ・あがりの5種類の効果音が鳴ります。ヘッダーのボタンでいつでも消せます。
- **ふりがな付きの画面**: 遊ぶ準備の画面と「あそびかた」の画面の漢字にはふりがなを振ってあり、低学年でも自分で読めます。
- **どんな端末でも画面に収まる**: 人数ごとのレイアウトを画面サイズに合わせて自動で拡大・縮小（最大1.25倍）するため、スマートフォンでもタブレットでも大型モニターでも見切れません。
- **PWA対応**: 「ホーム画面に追加」でアプリとして起動でき、2回目以降はオフラインでも遊べます。
- **記録を残さない**: 名前の入力欄はなく、成績も設定も端末に保存しません。遊んでいるあいだに外部と通信することもありません。

## 遊び方
1. **設定**: 人数（2〜6人）と制限時間を選んで「ゲームスタート！」を押します。
2. **お題を見る**: 画面中央の「今のお題」のカードが、次に言う言葉の1文字目です。
3. **言葉を言う**: お題の文字で始まり、自分の手札のどれかの文字で終わる、**3文字以上**の言葉を声に出します。
4. **カードを出す**: そのカードを1回タップすると浮き上がり、もう1回タップで場に出ます。指ではらう（スワイプする）と1回で出せます。
5. **詰まったとき**: 中央の山札を押すとお題をめくり直せます（パス）。自分の「山札から引く」を押すと手札が1枚増えます。
6. **勝利条件**: いち早く手札をすべてなくしたプレイヤーの勝ちです。あがったあとも画面はそのままなので、残った人で2位以降を決められます。

言葉が正しいかどうかをアプリは判定しません。ありかなしかは囲んでいる人たちで決めてください。

## アプリとしてインストールする（PWA）
- **Android / PC の Chrome**: アドレスバーのインストールアイコン、またはメニューの「アプリをインストール」を選択。
- **iPhone / iPad の Safari**: 共有ボタン → 「ホーム画面に追加」を選択。

インストール後はホーム画面のアイコンから全画面のアプリとして起動でき、2回目以降はオフラインでも動作します。

## 開発
```bash
npm install     # 依存関係をインストール
npm run dev     # 開発サーバーを起動
npm run build   # dist/ に本番用ビルドを出力
npm run preview # ビルド結果をローカルで確認
```

ゲームのロジックと画面は `src/App.jsx` にまとまっています。テストは用意していません。

### 技術スタック
- **Vite**: ビルドツール（公開パスは `/word_basket/`）
- **React 19**: UIコンポーネントライブラリ
- **Tailwind CSS**: スタイリング
- **Lucide React**: アイコンセット
- **Web Audio API**: 効果音の生成（音声ファイルは使っていません）
- **vite-plugin-pwa (Workbox)**: PWA対応（オフラインキャッシュ・自動更新）
- **GitHub Actions**: `main` への push で GitHub Pages へ自動デプロイ
